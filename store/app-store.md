## Description

Turn your iPhone sideways and use it as a trackpad and shortcut keyboard for your Mac. Move the pointer, click, drag, and scroll while keeping your most-used keys within reach.

Keep a vibe coding session going between sets at home. Leave the cursor in Claude Code or Codex on your Mac. In Relaypad, open Keyboard, dictate your next prompt with the iPhone keyboard, then tap Send to insert the text at the cursor.

The keypad starts with Fn, Control, Option, 1, 2, 3, and a wide Space key. Remap any key to a shortcut, hold a modifier while you tap another key, or double-tap Fn for Mac apps configured to use that gesture.

Get the free Relaypad for Mac companion from the project website. Put both devices on the same local network, start the Mac receiver, and enter its pairing code on your iPhone. Enable Accessibility for the receiver so it can deliver pointer and keyboard input. The devices reconnect using the saved pairing.

Relaypad uses an encrypted local connection. There is no account, subscription, advertising, or analytics. The iPhone app and Mac receiver are open source under the MIT license.

## App Review notes

A Mac running macOS 14 or later and an iPhone running iOS 17 or later are required for the end-to-end test. Download the free Mac companion from the marketing URL. No login or demo account is required.

1. Put the Mac and iPhone on the same local network and allow Local Network access when prompted.
2. Open Relaypad for Mac, start the receiver, and allow Relaypad in System Settings → Privacy & Security → Accessibility.
3. On the iPhone select Pair Mac, choose the Mac, and enter the code shown in its window.
4. Focus an empty TextEdit document. Move and tap with one finger, then tap 1, 2, 3, and Space on the phone. Use the sliders button to customize the keys.

The Mac companion is needed to test remote input. The phone shows the keypad, gestures, and settings before pairing.
