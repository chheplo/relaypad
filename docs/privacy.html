Privacy policy

Effective November 17, 2026. This policy covers Relaypad for iPhone, Relaypad for Mac and the project website, maintained by Pratik Desai.

Your input stays between your devices

Relaypad sends pointer movements, scrolls, clicks, key transitions and text you choose to send from your iPhone directly to your paired Mac. The Mac delivers them to the app you are using. Relaypad does not keep an input history, collect analytics, use ads, or send this input to the developer. Pairing works without an account or a cloud service.

Discovery, pairing and permissions

When the receiver runs, Bonjour advertises the Mac’s service name and a persistent receiver identifier on the local network. The encrypted session sends the phone’s display name to the Mac. Both apps use the pairing code to authenticate the TLS connection.

The phone stores a saved code for each paired receiver in Keychain. The Mac stores its receiver code in Keychain. The phone keeps its last receiver identifier, key mappings, sensitivity and haptic preferences in local app settings. Mac Accessibility permission lets the receiver post mouse and keyboard events. Local Network permission lets the devices find and connect to one another.

Your controls

Use Disconnect on iPhone to end the session and clear its automatic receiver selection. Choose Forget saved code for a Mac to remove that credential from the phone. On the Mac, Stop receiver closes connections and New code invalidates the old pairing code for all phones. You can also revoke permissions in system settings.

Dictation and other apps

Relaypad does not record or transmit microphone audio. Using iPhone keyboard dictation is governed by your keyboard provider and system settings. Triggering a Mac dictation app invokes that app’s microphone, processing and privacy choices. The resulting text and other input you send to a Mac app are subject to that app’s handling.

This website and support

This site serves static files and has no project analytics, tracking cookies or third-party embeds. GitHub hosts it and logs visitors’ IP addresses for security. If you open a GitHub issue, the content you submit is visible to people who can view that issue. GitHub Pages data collection · GitHub privacy statement
